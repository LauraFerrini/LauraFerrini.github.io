# PhD Academic Website

This is a minimal static academic homepage for GitHub Pages.

## Edit the Site

- Replace names, affiliation, contact details, papers, teaching, and awards in `index.html`.
- Replace `assets/profile-placeholder.svg` with your own photo, for example `assets/profile.jpg`.
- If you change the image filename, update the `src` value in `index.html`.
- Edit the research interests, papers, teaching, and service sections.

## Publish on GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all files from this folder into that repository.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Set the source to the `main` branch and root folder.
6. Your page will be available at `https://yourusername.github.io`.

For a project page instead of a personal homepage, create any repository name and publish with GitHub Pages. The page will be available at `https://yourusername.github.io/repository-name`.
